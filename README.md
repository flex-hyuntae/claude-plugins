# flex-hyuntae Claude Plugins

이 마켓은 더 이상 플러그인을 배포하지 않는다.

| 기능 | 옮긴 곳 |
| --- | --- |
| 위키 스킬 `add-topic`, `add-work`, `digest-wiki` | [eomttt/wiki](https://github.com/eomttt/wiki)의 `wiki` 플러그인 |
| Drill·Rules | [eomttt/agent-plugins](https://github.com/eomttt/agent-plugins) |

`flex-workflow`의 `deploy`, `test-package`, `setup-dev`, `i18n-convert`는 폐기했다.
기존 설치는 `claude plugin uninstall flex-workflow@flex-hyuntae-plugins`로 제거한다.
